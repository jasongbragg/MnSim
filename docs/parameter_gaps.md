# Parameter gaps: the six rust-affected species

Status: **for the user to set priors** (PLAN.md Phase 4). Written 2026-11-22. The table at the end
is generated by `scripts/csv_to_yaml.R --gaps`; the text above it is hand-written.

## 1. How a species file gets built

`scripts/csv_to_yaml.R <species>` writes `species/<sp>.yaml` from the species' rows in
`data/rust_species_params.csv` (notes T22). The CSV stays the single source, as for *M. nodosa*.
- **A model field is filled by a row named after it**: the schema path joined with `__`, for
  example `age_first_flower_mean` or `rust_dose_response__resprout__max_effect`, with role
  `parameter`. That row holds:
  - a cited value; or
  - a prior: notes starting `PRIOR [min, max]: reason` (or `PRIOR {a, b}: reason`); or
  - `derived` (only `annual_env_alpha` and `annual_env_beta`, which come from the shared anchor).
- **Literature rows under other names are evidence, not fields.** Examples are `longevity`,
  `generation_length` and `seed_fill`. `data/param_evidence_map.csv` links each to the fields it
  bears on, and section 5 lists them per species. Turning evidence into a prior is your judgement.
  It goes into the field row with its reason. The script never does it.
- **Modes decide which fields are needed.** For example, `sucker_rate` is needed only if
  `clonal_mode` is `genet`, and `damage_recovery` only in damage mode. So the mode choices
  (section 2) come first.
- **A species with any gap is not written.** The script prints the missing fields.
- **Check:** the script rebuilds *M. nodosa*'s parameters from its CSV exactly
  (`tests/testthat/test-csv-to-yaml.R`).

None of the six species has a field row yet. Every needed field is a gap, so all six are blocked
for now.

How these map onto the model:
- **Age at first reproduction** becomes `age_first_flower_mean` and `age_first_flower_sd`.
- **Longevity** becomes `weibull_lambda` and `weibull_k` (background mortality), plus
  `senescence_dose_response`.
- **Generation length is not a parameter.** The model infers T_g in each run (notes A3). The
  literature value is a check on the inferred T_g, and it sets the pre-rust window for estimating
  T_g (`assessment$year_gentime_start`, `assessment$year_gentime_end`).
- **For clonal species**, T_g counts sucker parents (T17). *U. australis* needs a clonal
  definition before its generation length means anything (Known data issues, PLAN.md).

## 4. Everything else, by group

- **Recruitment** (`R_max`, `K_half`, `juv_decline_*`, `shade_dose_response`, `selfing_rate`).
  - Little direct evidence: seed fill, short-lived seed with no seed bank, population sizes.
  - Probably wide priors, with population size and seedling presence as constraints.
- **Fire** (`fire_*`, `resprout_*`, `fire_exposure`).
  - All the species resprout.
  - *U. australis* has 2019–20 fire impacts, and *R. rubescens* has a post-fire mortality target.
  - Exposure priors for the rainforest species: T15.
- **Rust.**
  - `rust_dose_response`: the main fitted terms, with the most calibration targets.
  - `rust_site_sd`: spread between sites.
  - Damage and fruit terms: T19–T21.
- **Mechanical fields** (same kind of choice as for *M. nodosa*). I can draft these rows for you
  to check:
  - `rust_pressure` = 1, a neutral multiplier;
  - `annual_env_alpha` and `annual_env_beta` derived from the shared anchor;
  - `microclim_alpha` and `microclim_beta`;
  - fixed values for terms that are off, such as the `form` and `hill` of a dose response whose
    `max_effect` is 0;
  - `resprout_prob_recovery` when recovery is `countdown`;
  - `fire_extent_mode`.
- **Resistance** (`resist_*`). Placeholders only, under CLAUDE.md rule 1: one locus, starting
  frequency 0, as for *M. nodosa*. Field reports of low-damage populations and surviving clumps
  are listed as evidence, but the real data stay in `private/`.
- **Assessment and range.**
  - `assessment$year_spinup` and the T_g window follow from generation length.
  - `spatial$range_box` comes from each species' occurrence data. Only *M. nodosa* has spatial
    data so far.
